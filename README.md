## 🧭 Project Description

This repository presents the complete work carried out during my **Cybersecurity Internship at Redynox**, held remotely between **September 21 and October 20, 2025**.  
The internship aimed to strengthen both **practical and theoretical knowledge** in cybersecurity through two structured technical missions:

1. **Task 1 — Network Security Fundamentals:**  
   Focused on understanding and securing network infrastructures.  
   It included the configuration of a **virtual lab** with pfSense, Kali Linux, and Ubuntu, the implementation of **WPA2/WPA3 wireless encryption**, and the analysis of network traffic using **Wireshark**.  
   The goal was to demonstrate a layered defense approach combining firewalls, encryption, and monitoring.

2. **Task 2 — Web Application Security:**  
   Dedicated to discovering and mitigating common web vulnerabilities using **OWASP ZAP** and the intentionally vulnerable web app **bWAPP**.  
   It covered the identification and exploitation of **SQL Injection**, **Cross-Site Scripting (XSS)**, and **Cross-Site Request Forgery (CSRF)**, followed by the implementation of mitigation strategies based on **secure coding principles**.

---

### 🎯 Internship Objectives

- Strengthen my understanding of **network and web security fundamentals**.  
- Learn to deploy and test secure environments using **real tools and simulated attacks**.  
- Gain experience in **vulnerability analysis**, **incident monitoring**, and **security best practices**.  
- Produce **professional technical documentation** using **LaTeX**, aligned with industry reporting standards.

---

### 🧰 Deliverables

Each task includes:
- 📘 A complete **LaTeX report** with screenshots, explanations, and mitigation recommendations.  
- 🧪 All related **laboratory configurations and screenshots**.  
- 🧩 A final reflection on security hygiene, awareness, and defensive architecture.

The internship reports were **validated by Redynox Lead Supervisor Ankit Mathur** and are now published here for **educational and portfolio purposes**.
